2 · Какой канал считать группе: Радио или Интернет

По каждой группе супервайзера в категории "Радио/Интернет" учитывается только один из каналов. Угадать по сумме продаж нельзя — у части групп основной канал не совпадает с тем, где больше денег. Проверьте/поправьте вручную.

3 · Результат

Сравнение с предыдущим периодом того же типа (неделя ↔ неделя, день ↔ день), загруженным ранее в Supabase. Клик по ФИО в любой таблице открывает персональный график.

Логика расчёта

Внутри группы по каждой категории (1 обращение, ЛК, радио/интернет, время/контакт, % ошибок) считается место (чем больше продажи / меньше время и ошибок — тем выше), балл = место × вес (×3 / ×1.5 / ×2.5 / ×1 / ×1), из суммы баллов — итоговое место.
Н/О — статус Новичок/Тренер/руководитель/Отпуск/Больничный или нулевые продажи — в основной таблице группы не участвуют в месте.
Новички ранжируются одним общим списком по всей компании, а не внутри группы.
Рейтинг супервайзеров — карточки и сумма считаются как сумма по группе, остальные показатели (ср.чек, конверсия, сумма с контакта, время, ошибки) — как среднее среди "оценённых" (не Н/О) сотрудников группы, дальше та же логика мест и весов.
